paopalmnursery.com

เว็บไซต์บริษัท + หลังบ้านจัดการเนื้อหา + AI แชตบอต — บจก. พี่เป้า อะโกเทค (แปลงเพาะต้นกล้าปาล์มน้ำมัน นครศรีธรรมราช)

  • ทีมบริษัทแก้ข่าว บล็อก แกลเลอรี สินค้า เองผ่านหลังบ้าน พร้อมคู่มือ
  • แชตบอต AI ตอบคำถามลูกค้าจากคลังความรู้ของเว็บ
  • ตั้งค่า SEO/AEO ครบ (Schema, Sitemap, llms.txt)
  • บนโดเมนจริง รันบน Vercel + Cloudflare + Vercel Blob
kantawatgarden.com
kantawatgarden.com

เว็บสินค้าและบริการ + CMS ให้เจ้าของแก้เอง — ไร่หญ้ากันตวัฒน์ (หญ้าปูสนาม/ต้นไม้/จัดสวน นครนายก)

  • เจ้าของร้านแก้สินค้า บทความ แกลเลอรี เองผ่าน Sanity CMS เว็บอัปเดตในไม่กี่นาที
  • SEO ท้องถิ่น + structured data ติดหน้าค้นหาจริง
  • โหลดไว รองรับมือถือ ปุ่มโทร/LINE/WhatsApp/Messenger
ระบบภายในของร้าน — คลิปสาธิตจัดส่งได้ตามคำขอ
Thai Aroi POS — ระบบขายหน้าร้านและรับคำสั่งอาหาร

ร้านอาหารไทย กรุงมาเล (Malé) มัลดีฟส์ — ใช้งานจริงทุกวัน

  • ลูกค้าสั่งอาหารผ่านมือถือหลายภาษา ติดตามสถานะออเดอร์สด
  • บอร์ด POS และหน้าครัวเห็นออเดอร์เรียลไทม์ (WebSocket)
  • บิลหลายสกุลเงิน (USD/MVR) ภาษี ค่าบริการ ส่วนลดยืนยันด้วย PIN พิมพ์ใบเสร็จความร้อน 80 มม.
  • ระบบสต๊อกตัดของอัตโนมัติ นำเข้า/ส่งออก Excel รายงานยอดขายรายวัน
  • ผ่าน security audit มีรายงานอัปเกรดเวอร์ชันและดูแลต่อเนื่อง

utoevent.com

แพลตฟอร์มอีเวนต์ — บจก. สไวป จำกัด (ผู้จัดแฟนมีตติ้ง)

  • เว็บหลักของอีเวนต์จริง (แฟนมีตติ้ง ต.ค. 2026) เปิดใช้งานแล้ว
  • วางแผน 3 เฟส: e-Commerce → ระบบจองตั๋วแบบเลือกที่นั่ง + QR สแกนเข้างาน (กำลังพัฒนาเฟสต่อ)
  • จัดทำเอกสาร SRS และข้อเสนอโครงการระดับบริษัทครบชุด

สิ่งที่รับทำ

ตั้งแต่วางโครงเว็บ พัฒนา ตั้งค่า SEO/AEO จนถึงดูแลหลังส่งมอบ

เว็บไซต์ธุรกิจ + หลังบ้าน CMSทีมแก้เนื้อหาเองได้ พร้อมคู่มือและอบรม
SEO / AEO / GEOSchema, Sitemap, llms.txt ให้ Google และ AI Search เข้าใจ
ระบบ POS / จอง / อีคอมเมิร์ซรับเงิน รายงาน สต๊อก ใช้งานจริงหน้าร้าน
เชื่อม AIแชตบอตตอบจากคลังความรู้ automation งานประจำ
โยกย้ายระบบเดิมอย่างปลอดภัยเว็บใหม่บนโครงเดิม ข้อมูลและระบบที่ใช้อยู่ไม่พัง
ดูแลต่อเนื่องหลังส่งมอบอัปเดต แก้ไข ต่อยอดฟีเจอร์ ตามการใช้งานจริง
